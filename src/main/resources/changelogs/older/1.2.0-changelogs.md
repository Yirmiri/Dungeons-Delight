## Forgotten Frights || v1.2.0 Forge-1.20.1

### Notes
- The license has been slightly updated to open some wiggle room for addons, if this affects you it's recommended to read over the new version
- While this version of Dungeon's Delight can run on most 1.20.1 versions of Farmer's Delight, it is recommended to update as some
features may not work properly without the new tags introduced in **Farmer's Delight version 1.2.8**

### Credits
- Thanks to @Hecco56 for the help with Wormroot generation and their stalks
- Thanks to @Artyrian for the custom splashes

### Additions
- Added Silverfish and Chips, a new feast block that when scooped into a bowl grants Burrow Gut, Voracity, and converts poison into a short regeneration
- Added Wormroot Stalks, these can be connected to when placed and are bonemealable
- Added Wormouths, at the end of natural Wormroot Stalks will be Wormouths, when fed it will spit out an item, the items will
vary based on if the Wormouth liked the food or not. When fed more than 3 times it will have a 50% chance to close to digest but
will reopen after a short duration
- Added Gunk Arrows, mobs that are hit by these will be targeted by undead monsters
- Added Putrid Scent, a negative mob effect that lures undead monsters towards the user
- Monster Yam can now occasionally summon Zombies if none are nearby
- Monster Yam will now go towards crops and rot them
- Monster Yam will now inflict Putrid Scent to attacked entities, duration is based on difficulty
- Monster Yam now take 2x damage from hoes, knives, and cleavers
- Stained Scrap can now be used as a trim material
- Added special splash texts for Dungeon's Delight
- Translations have been added for ru_ru, Russian (Credits: @Serperch)
- Translations have been updated for zh_tw, Chinese (Traditional) (Credits: @DEEMsss)

### Changes
- Renamed & updated the id of all instances of the word "Wormroots" -> "Wormroot Tendrils"
- Wormroot Tendrils now craft 2 Wormwood Planks rather than 1
- Wormroot Tendrils can no longer be grown using Monster Foods
- Block of Wormroots no longer can create Wormwood Planks
- Monster Yam's armor has been increased from 2 -> 6
- Monster Yam's movement speed has been increased from 0.24 -> 0.25
- Monster Yam's follow range has been increased from 24 -> 32
- Reduced the throwing range on Stained Scrap Cleavers from 2.0 -> 1.75
- Smoked Spider Meat can now drop instead of Spider Meat if the Spider is on fire (this allows Fire Aspect on Knives and charged stain tools to work on them)
- Stained Knives and Stained Cleavers now require Netherite Scrap instead of a Diamond
- Living Torches now only need a Stained Scrap Fragment rather than an entire Stained Scrap

### Tweaks
- All monster mob effects are now considered neutral effects due to them taking away the ability to obtain the base variant
- Slightly changed the model for a stack of five hanging Spider Donuts to connect better

### Technical
- Added `flaming_knives` item tag, this will make melee attacks from INKnifeItem or CleaverItem items cause 
entities to burn for 4 seconds, this will additionally cause thrown CleaverItems to burn for 4 seconds, by default this 
tag has Fiery Knife and Fiery Cleaver from this mod's Twilight Forest integration
- Stained Knives and Cleavers now use `repairs_stained_tools` tag for repair ingredients rather than it 
being hardcoded to Stained Scrap, this tag has just Stained Scrap in it by default
- Added the corresponding Dungeon's Delight foods to the new Farmer's Delight tags; `meals`, `drinks`, and `feasts`
- Added `disableContentIntegration` config value, when this is enabled then all integration items will be disabled
- Updated the description of the `forceEnableCompatItems` config value

### Fixes
- Serrated Strike should no longer count as a treasure enchantment
- Cleavers with Fire Aspect have been corrected to burn entities for `(100 ticks * level)` rather than `(100 seconds * level)`,
this does not mean Fire Aspect will be obtainable on Cleavers however

## Mod Integration

- [Twilight Forest] Added Knives and Cleavers for Ironwood, Knightmetal, Steeleaf, and Fiery materials, Fiery has the added
bonus of burning entities for a few seconds
