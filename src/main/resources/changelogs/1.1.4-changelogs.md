## v1.1.4 Forge-1.20.1

### Notes
- The license has been slightly updated, if this affects you it's recommended to read over the new version

### Additions
- Added the corresponding Dungeon's Delight foods to the new Farmer's Delight tags; `meals`, `drinks`, and `feasts`
- Added `disableContentIntegration` config value, when this is enabled then all integration items will be disabled
- Translations have been updated for zh_tw, Chinese (Traditional) (Credits: @DEEMsss)

### Changes
- Reduced the throwing range on Stained Scrap Cleavers from 2.0 -> 1.75
- Smoked Spider Meat can now drops instead of Spider Meat if a Spider is on fire (this allows Fire Aspect on Knives and charged stain tools to work on them)
- Stained Knives and Stained Cleavers now require Netherite Scrap instead of a Diamond
- Living Torches now only need a Stained Scrap Fragment rather than an entire Stained Scrap
- Updated the description of the `forceEnableCompatItems` config value

### Tweaks
- Slightly changed the model for a stack of five hanging Spider Donuts to connect better

### Fixes
- Serrated Strike should no longer count as a treasure enchantment
