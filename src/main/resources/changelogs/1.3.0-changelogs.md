## Tasty Trials Update || v1.3.0 NeoForge-1.21.1

### Wiki Reminder
- We have a wiki you can use to search any questions you may have regarding the mod! 
You can check it out at: https://dungeonsdelight.wiki.gg/

### Additions
- Ported the mod to version NeoForge 1.21.1
- Added 2 new splash texts

### Changes
- Most foods that do not give a monster effect or have a purple name are now made in Farmer's Delight's normal cooking pot
- Foods that required cooked variants in their monster cooking recipes now required the raw variant
- Monster Muffins now output x2 when cooked
- Spider Donuts now output x2 when cooked
- Devilish Eggs now output x2 when cooked
- All Sculk foods now grant x2 the experience of what their food type normally would give
- Tweaked the recipe of Ominous Omelette to now take x1 of each mushroom rather than any of x1
- Ossobuco now takes 400 ticks to cook rather than 200 ticks
- Cob n' Candy can no longer be made using Cobwebs however the String recipe has been reduced from x5 String to x3 String
- Rubaboo no longer can be made using Honey Bottles
- Rubaboo now takes 200 ticks to cook rather than 100 ticks
- Embedded Eggs now cost 5 eggs but drop 5 Ancient Eggs
- Cleavers now deal knockback when hitting an entity

### Tweaks
- Ravenous Rush no longer will have the Monster Effect background to allow the background to be an indicator for effects
  that convert but will keep it's colored text
- A new particle will appear when thrown Rancid Reduction hits a block

### Fixes
- Fixed Sculk Polyps not stacking past 1
- Fixed an issue with the Bloody Mary item not converting Haste into Burrow Gut
- Brined Flesh and Gritty Flesh can now be fed to Wolves
- Fixed an issue that caused Cleavers to set entities on fire for a long time if they were on fire
