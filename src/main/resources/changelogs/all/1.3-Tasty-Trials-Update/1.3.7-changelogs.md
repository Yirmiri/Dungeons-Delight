## Tasty Trials Patch || v1.3.7 NeoForge-1.21.1

### Wiki Reminder
- We have a wiki you can use to search any questions you may have regarding the mod! 
You can check it out at: https://dungeonsdelight.wiki.gg/

### Additions
- Added Chiseled Stained Scrap, this inherits Stained Scrap Block's old texture (read tweaks for more information)
- Added Stained Scrap Pillars
- Added Stained Scrap Doors and Stained Scrap Trapdoors

### Changes
- Stained Scrap is no longer craftable from Stained Scrap Blocks
- Stained Scrap Grates now allows items to be placed inside of them
  - When an item is placed inside it will whitelist just that item to be passable through the block
  - Items placed inside will rotate like spawners
  - Enhancements can be applied to the block via various items which will change some visuals on it
    - Honeycomb is an enhancement to freeze item spin rotation
    - Redstone Dust is an enhancement to speed up the item spin rotation (cannot be applied if waxed)
    - Glowstone Dust is an enhancement to increase the size of the item
  - Named items will display their name above the block
  - Stained Scrap Grates now has an item tooltip similar to Spawners

### Tweaks
- Remodeled and textured Living Lanterns
- Updated the texture of Stained Scrap Blocks, the old texture is now used for Chiseled Stained Scrap
- Slightly tweaked the texture of various Stained Scrap items
- Resorted Stained Scrap in the creative inventory

### Fixes
- Fixed an issue where Spider Donuts that have been stacked twice would only drop x1 Spider Donut (Issue #72)
- Fixed a crash when placing Wormwood Cabinets (Issue #73)
- Fixed an issue where Dungeon's Delight scavenging drops would always drop regardless if a Knife or Cleaver was used or not

## Integration

- [Twilight Forest] Fixed Aurora Ice Cream attempting to take Forge's common milk tag instead of the conventional/NeoForge tag
